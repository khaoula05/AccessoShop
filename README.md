# AccessoShop
E-Commerce AccessoShop website developed with Spring Boot, REST API, CI/CD, JUnit testing and SonarQube integration.
## CI/CD Pipeline

Le projet utilise GitHub Actions pour :

- Compiler automatiquement le projet Spring Boot
- Exécuter les tests Maven
- Vérifier la qualité du code avec SonarCloud
- Valider chaque push et pull request
